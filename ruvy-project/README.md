# ruvy.project / 2.0

Это самостоятельная версия. Исходный сайт и HTML-референс не изменены.

Откройте папку `ruvy-2.0` в VS Code, а `index.html` — в браузере. Папку `ruvy-project` сохраняйте рядом с HTML. Сайт работает локально, в том числе без интернета: Manrope и Unbounded включены вместе с лицензиями OFL.

## Что изменилось

- Сохранены структура, оранжевый акцент, графитовая основа и светлый блок услуг.
- Добавлены выразительная типографика, контурная часть названия и появление текста из маски.
- Первый экран стал компактнее; оффер конкретизирует Reels, Shorts и YouTube.
- Кнопка «Обсудить проект» открывает Telegram. Переход к работам — рядом.
- В меню появились этапы работы. Добавлены индикатор прокрутки, мягкая подсветка, каскадное появление и подсветка этапов.
- Анимацию можно отключить кнопкой в шапке. Настройка уменьшения движения на устройстве имеет приоритет.
- Заглушки работ остались неинтерактивными, число опубликованных работ равно нулю. Медиа и отзывы не добавлены.

## Редактирование

- `styles.css` — оформление; новые правила находятся в секции «2.0».
- `app.js` — навигация, диалог, движение.
- `data/content.json` — контакты и будущие работы.
- `assets/fonts/` — локальные шрифты; `assets/favicon.svg` — иконка сайта.

После изменения данных выполните из папки `ruvy-project`:

```sh
npm install
npm run sync
npm run check
```

Установка инструментов нужна только при разработке. На готовом сайте Node.js и сборщик не нужны. Для воспроизводимой установки с lockfile можно использовать `pnpm install --frozen-lockfile`.

Работа публикуется только при `published: true`, заполненном названии и пути к MP4/WebM. Поддерживаются пути `ruvy-project/assets/...` и HTTPS-ссылки на файлы. Тексты и обложки экранируются/проверяются при генерации. Без JS доступны обычные ссылки на видео, а с JS — диалог.

## Просмотр и проверки

```sh
node scripts/serve.mjs
npm run check
```

Адрес предпросмотра: http://127.0.0.1:4192. Сервер останавливается Ctrl+C. Ключ `--qa` включает временные страницы `/__qa/dialog` и `/__qa/no-js` для проверки диалога и страницы без JavaScript; тестовые работы не записываются в портфолио.

Добавлены favicon, Open Graph и JSON-LD с известными данными. Canonical, `og:url` и абсолютный `og:image` нужно заполнить после выбора реального домена — фиктивный адрес не установлен. Название 2.0 относится к версии исходников, а не к новому бренду.
